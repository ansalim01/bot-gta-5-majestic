Маршруты шахтёра

Полная инструкция находится в README.md в этой же папке.
Установка проекта описана в ../../README.md.

Из корня проекта после установки зависимостей:
  .\.venv\Scripts\python.exe tools/record_route.py my_to_drop

F11 — начать запись; повторное F11 — остановить и сохранить.
Сначала дождитесь сообщения Saved:, затем нажмите Esc для выхода.
Новое имя сохраняет общие маршруты; сохранение с прежним именем перезапишет файл.

Назначение маршрутов: navigation.routes в config/user/miner.yaml.
Запуск шахтёра: .\.venv\Scripts\python.exe main.py, затем F9.
Остановка шахтёра: F10.
