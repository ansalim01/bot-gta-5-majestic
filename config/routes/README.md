# Маршруты шахтёра

[← Первый запуск проекта](../../README.md) · [Настройки шахтёра](../../docs/configuration.md#шахтёр)

Маршрут — YAML с записанными нажатиями W/A/S/D/Shift и относительными движениями мыши.
Он воспроизводит движения из заданного начального положения. Подойдите в ту же
точку и поверните камеру в ту же сторону: запись не строит новый путь автоматически.

Все команды ниже выполняются **из корня проекта**, например `C:\game-bot`,
после установки зависимостей в `.venv`. Во время записи остановите игровые боты.

## Что лежит в этой папке

Общая конфигурация шахтёра использует:

| Файл | Назначение |
| --- | --- |
| `fork_tunnel2.yaml` | Развилка → камень второго туннеля |
| `mine_to_drop.yaml` | Камень → место сдачи |
| `drop_to_fork.yaml` | Место сдачи → развилка |

Эти записи привязаны к исходному месту и направлению камеры. Для своего пути
используйте новое имя, чтобы сохранить общие файлы проекта.

## Записать свой маршрут

Пример: путь от камня до места сдачи под новым именем `my_to_drop`.

```powershell
.\.venv\Scripts\python.exe tools/record_route.py my_to_drop
```

1. Оставьте программу записи работающей и вернитесь в игру.
2. Встаньте в начало пути и установите камеру так, как она будет стоять при запуске бота.
3. Нажмите **F11**, чтобы начать запись. По умолчанию эта клавиша берётся
   из `hotkeys.record_toggle` конфигурации шахтёра.
4. Пройдите нужный путь с клавишами движения и поворотами камеры.
5. В конце снова нажмите **F11**. В консоли должно появиться `Saved:` с путём
   к `config/routes/my_to_drop.yaml`.
6. После подтверждённого сохранения нажмите **Esc**, чтобы выйти из программы записи.

Сохраняйте запись через F11 до выхода через Esc. Повторное начало записи очищает
предыдущие события в памяти, а сохранение с тем же именем перезаписывает файл.
Взаимодействия вроде E и кликов мини-игры этим инструментом не записываются.

Если F11 занята, укажите другую поддерживаемую клавишу вторым аргументом:

```powershell
.\.venv\Scripts\python.exe tools/record_route.py my_to_drop f12
```

Для полного цикла аналогично запишите путь к камню `my_to_rock`
и возврат к развилке `my_after_drop`.

## Подключить записи

Остановите шахтёра. В `config/user/miner.yaml` укажите имена **существующих**
файлов без расширения `.yaml`:

```yaml
mode: full
navigation:
  enabled: true
  mode: routes
  routes:
    to_rock: my_to_rock
    to_drop: my_to_drop
    after_drop: my_after_drop
```

Если личный файл уже содержит раздел `navigation`, объедините поля внутри него.
Не добавляйте второй раздел с тем же именем. Каталог маршрутов задаётся
параметром `routes.directory`; по умолчанию это `config/routes`.

Затем запустите шахтёра и включите его F9 в нужном начальном положении:

```powershell
.\.venv\Scripts\python.exe main.py
```

Для остановки используется **F10**. Не записывайте новый маршрут одновременно
с воспроизведением старого. Если персонаж идёт неверно, остановите сценарий,
проверьте исходную точку, направление камеры и назначенные имена файлов.

## Если редактируете YAML вручную

`events` должен быть списком событий со временем `time_ms` в миллисекундах
от начала записи. Времена должны быть конечными, неотрицательными и не убывать.
Поддерживаются `keydown`, `keyup`, `press` с полем `key`, а также `mouserel`
с целочисленными `dx` и `dy`. Пустой маршрут не запускается; неверные события
отклоняются до начала воспроизведения.
