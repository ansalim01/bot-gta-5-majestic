## Окружение

Откройте PowerShell в корне исходников, где находятся `launcher.py` и `requirements-dev.txt`.
Для работы над кодом нужны дополнительные зависимости из `requirements-dev.txt`:

```powershell
cd "C:\game-bot"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Замените путь своим. Если `.venv` уже создана по README, повторять её создание
не нужно — выполните только установку `requirements-dev.txt`. Все команды ниже
используют это окружение без активации. В CI проверяются Python 3.11 и 3.13.

Проект запускается из исходной папки; установка Python-пакета не требуется.
Для реального ввода и захвата нужна Windows. Не запускайте два экземпляра,
которые одновременно управляют игровым окном.

Панель можно открыть для разработки без запроса UAC:

```powershell
.\.venv\Scripts\python.exe launcher.py --no-elevate
```

Этот режим предназначен для интерфейса. Запуск игрового процесса из панели
сохраняет права панели.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe -m pytest
```

Для применения форматирования:

```powershell
.\.venv\Scripts\python.exe -m ruff format .
```

Конфигурация находится в `pyproject.toml`: Python 3.11, отступы в четыре
пробела, длина строки 100, проверки синтаксиса, импортов и неиспользуемых имён.
`.editorconfig` и `.gitattributes` задают UTF-8 и LF для текстовых файлов.

Файлы рабочего заброса `bot/detectors/cast_timing.py` и `bot/jobs/fisher.py`
исключены из форматирования, чтобы сохранить их без изменений.
Для существующих импортов в них указаны точечные исключения линтера.
Это ограничение связано с проверенным поведением в игре, а не с разрешением
добавлять аналогичные исключения в новый код.

Запускайте **pytest**: в проекте есть и классы unittest, и тестовые функции.
Один `unittest discover` не проверяет все сценарии блэкджека.
`testpaths = ["tests"]` исключает интерактивные `tools/test_*.py` из коллекции.

Тесты Qt работают с `QT_QPA_PLATFORM=offscreen` и темой приложения.
В Windows-окружении без автоматического обнаружения шрифтов тестовая фикстура
загружает установленные Segoe UI из каталога Windows Fonts. Это позволяет
проверять переносы и размеры текста, а не квадраты вместо букв.

## Что проверять при изменениях

| Изменение | Проверка |
| --- | --- |
| Стратегия | Границы сумм, мягкие руки, сплит, дабл; независимость от устройств |
| Игровая задача | Последовательность кадров, отсутствие повторных решений, лимиты повторов, запрет ввода |
| Детектор | Положительные и отрицательные кадры, похожие элементы, пропадание области |
| Конфигурация | Слияние переопределений, неверный YAML, сохранность файла при ошибке |
| Рабочий процесс | Частичные строки/UTF-8, последнее событие, неудачный старт, остановка старого процесса |
| Панель | Подписи, границы значений, клавиатура, штатный и минимальный размер окна |

Добавляйте тест на наблюдаемое поведение или реальную регрессию.
Перестановка импортов и перенос строк не требуют отдельных тестов.

## Ручная проверка в игре

Автотесты не подтверждают реальную задержку ввода и работу GDI на конкретном
компьютере. После изменения захвата, ввода, детекторов или игровых переходов
проверьте несколько полных циклов сценария, паузу, F10 и повторный запуск.
Убедитесь, что удерживаемые клавиши отпускаются, а нажатия при потере фокуса
соответствуют настройкам сценария.

Для рыбалки отдельно проверяйте тайминг заброса. Ограничения рабочего алгоритма
описаны в [правилах тайминга](fishing-timing.md).
Важны один вызов анализа на тик, фиксированная область кадра, отсутствие
подстановки позиции при потере ползунка и ограничение частоты отладочных снимков.

## Публикация

В Git должны попадать исходники, общие конфигурации, используемые шаблоны,
тесты и документация. Пользовательские YAML, журналы, кеши, окружение и временные
проверки исключены через `.gitignore`. Папка `.dev-tools/` предназначена только
для локальных средств проверки и не является частью поставки.

Не прикладывайте к issues необработанные снимки игры или полный каталог `logs/`.
Для воспроизведения ошибки достаточно соответствующего фрагмента кадра
и описания настроек; предварительно удалите чат, контакты и игровые ID.
