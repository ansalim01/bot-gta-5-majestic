# Решение проблем

[← Первый запуск](../README.md) · [Настройки сценариев](configuration.md)

Команды выполняются в PowerShell из папки проекта. Перед проверкой файлов настроек
остановите бота; перед ручным изменением YAML завершите панель через трей.

## Команда `python` не найдена или открывается Microsoft Store

Проверьте установленный Python и откройте новое окно PowerShell после установки.
Если доступен Python Launcher и установлен Python 3.13:

```powershell
py -3.13 --version
py -3.13 -m venv .venv
```

Если обе команды `python` и `py` недоступны, сначала установите Python для Windows.
После создания окружения остальные команды проекта используют явный путь
`.\.venv\Scripts\python.exe`.

## Не найден `launcher.py`, `requirements.txt` или Python из `.venv`

Скорее всего, открыта не та папка либо окружение ещё не создано:

```powershell
cd "C:\game-bot"
Get-Item .\launcher.py, .\requirements.txt
```

Замените `C:\game-bot` своим путём. Если файлов нет, найдите папку с исходниками,
в том числе внутри распакованного ZIP. Если нет только `.venv`, выполните шаг 2 README.
После перемещения проекта старое окружение может не работать; создайте новое
окружение в новой папке и установите в него зависимости.

## `ModuleNotFoundError`, не найден PySide6, cv2 или другой модуль

Установка и запуск должны использовать один Python:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

`cv2` устанавливается зависимостью `opencv-python` из `requirements.txt`.
Не заменяйте её случайным пакетом с похожим именем. Если `pip` завершился с ошибкой,
сначала устраните её: запуск после неполной установки не проверяет приложение.

Двойной клик по `.pyw` и скрипт создания ярлыка могут выбрать другой интерпретатор.
Для проверки используйте команды выше; [запуск без консоли](configuration.md#запуск-панели-без-консоли)
настраивайте после успешного обычного запуска.

## PowerShell запрещает `Activate.ps1`

Для инструкций этого проекта активация не нужна. Запускайте команды через
`.\.venv\Scripts\python.exe`; менять политику выполнения всей системы не требуется.

## Панель не открылась или исчезла

Проверьте запрос UAC. Если он был отменён, повторите обычный запуск и подтвердите его.
Посмотрите вывод консоли запуска. После запуска сценария панель автоматически
сворачивается — это ожидаемо. Значок GameBot находится в трее рядом с часами,
иногда под стрелкой `^`; нажмите его, чтобы вернуть окно.

Крестик также сворачивает панель. Для полного выхода используйте правую кнопку
по значку → «Завершить приложение». Если неясно, работает ли бот, нажмите F10
при стандартных настройках и проверьте состояние в панели.

## Бот ничего не делает

1. Посмотрите состояние на странице сценария и сообщения в «Журнале».
2. Если запускали **из консоли**, нажмите F9. Если нажали **«Запустить» в панели**,
   дополнительная F9 поставит уже работающего бота на паузу.
3. Вернитесь в окно GTA, закройте чат и посторонние меню.
4. Проверьте место и ожидаемую подсказку: приглашение рыбалки E, тренажёр или стол.
5. Проверьте разрешение, масштаб, язык, шрифт, монитор и отладочный кадр.

После F10 консольный процесс завершается, а в панели сценарий становится доступен
для нового запуска. Для новой сессии повторите команду или нажмите «Запустить».

## Распознаётся другой экран или не та область

Общие настройки рассчитаны на 1920 × 1080, масштаб 100% и русский интерфейс
с ProximaNova. Отключите наложения, перекрывающие HUD.
Для сценариев с `screen.force_monitor: true` проверьте `screen.monitor_index`
и соответствующий диагностический кадр. Подробности — в
[настройке монитора](configuration.md#монитор-калибровка-и-изображения).

Если требования выполнены, сохраните полный скриншот и проверьте детектор
офлайн. Пороги и координаты меняйте после сравнения кадров, а не наугад.

## Не открывается инвентарь, не используется еда или вода

Без индикатора голода или жажды сервис не открывает инвентарь. В отдельном
работающем сценарии F8 запрашивает проверку; на паузе запрос ждёт продолжения.
Проверьте, что Cola и батончик действительно находятся в инвентаре
и соответствуют настроенным шаблонам. Клавиша открытия инвентаря по умолчанию I.

Встроенная проверка рыбалки сначала выходит из активности, затем работает
с инвентарём. При неудачных повторах проверьте журнал и
`logs/sustenance_inventory.png`, если кадр был сохранён.
Не запускайте второй процесс обслуживания параллельно рыбалке или качалке.

## Блэкджек делает ставки в режиме советчика

Режим советчика и автоставки независимы. Выключите **оба** параметра:
«Автоматически нажимать» и «Автоматически ставить». Затем полностью остановите
сценарий и запустите его заново. Пауза/продолжение не применяет настройки.

## Настройки не применяются или страница сообщает об ошибке YAML

Изменения в панели применяются после полной остановки и нового запуска сценария.
После ручного изменения YAML нужно также заново открыть саму панель.
Личные значения в `config/user/` имеют приоритет над общими `config/*.yaml`.

Проверьте файл и поле, указанные в ошибке: отступы пробелами, числа без кавычек,
`true`/`false` без кавычек, существующие варианты выбора и разные управляющие клавиши.
Не создавайте второй раздел с тем же именем. Чтобы вернуть общие значения,
воспользуйтесь [инструкцией сброса](configuration.md#личные-настройки).

При ошибке загрузки страница блокирует сохранение и запуск, чтобы не перезаписать
конфигурацию неполным набором значений.

## Отчёта нет или на странице показана старая сессия

Проверьте параметр `telemetry.enabled` и завершите сценарий обычной остановкой.
Папки `logs/fishing_sessions` и `logs/blackjack_sessions` создаются при работе
телеметрии. Сверьте идентификатор сессии: при отключённой записи старый
`latest_summary` остаётся на диске. Ошибки записи ищите в журнале.

## Как описать проблему

Укажите сценарий, способ запуска, версию Python, разрешение и масштаб экрана,
шаги до ошибки и ожидаемое поведение. Приложите текст ошибки из журнала,
подходящий кадр и отчёт нужной сессии, если они появились.
Перед публикацией материалов уберите персональные данные с игровых кадров и из путей.
