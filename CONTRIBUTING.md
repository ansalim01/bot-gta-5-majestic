# Вклад в GameBot

Для локальной разработки нужны Windows и Python 3.11+. Подготовка окружения
и команды проверки описаны в [руководстве разработчика](docs/development.md).

Перед изменением игрового поведения воспроизведите проблему на сохранённом
кадре или искусственной последовательности состояний. Добавьте тест, который
падает на исходной реализации, затем исправляйте код. Для рефакторинга сохраняйте
порядок действий, задержки и формат событий.

Используйте Ruff для оформления кода. Давайте функциям имена по действию,
которое они выполняют; комментарии должны объяснять ограничения игры и причины
решения. Не объединяйте исправление игрового алгоритма с массовым форматированием.

Новый сценарий подключается через отдельную задачу, точку входа и метаданные
панели. Последовательность подключения описана в [архитектуре](docs/architecture.md).
Настройки пользователя хранятся отдельно от общих YAML; не добавляйте в изменения
свои локальные настройки, журналы, записи игровых сессий или временные инструменты.

В pull request укажите проблему, итоговое поведение, выполненные проверки и
результат ручной проверки в игре, если менялись распознавание, ввод или тайминги.
